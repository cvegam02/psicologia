# Project Standards (PsicologIA)

These rules must be followed for all development tasks in this repository.

## 🎨 Branding & Frontend
- **Branding Fidelity**: All UI elements must strictly adhere to the brand's color palette (e.g., Bronze, Espresso, Silk, Cream). No default browser or generic colors allowed.
- **Custom Dropdowns**: Any new dropdown or selection component must implement custom high-fidelity designs for its options, maintaining the "Premium" look of the current modals.

## 📱 Mobile & PWA (Mobile Design System)
- **PWA Context**: This is a Progressive Web App. All designs must be touch-friendly and responsive.
- **Touch Targets**: Minimum interactive area of 44x44px or 48x48px.
- **Performance**: Optimize lists and heavy state transitions to ensure 60fps-like smoothness on mobile devices.
- **Platform Respect**: Use patterns that feel natural on both iOS and Android.

## 🧩 Component Architecture
- **Reuse First**: Before creating a new component, search the codebase for existing elements that can be reused or extended.
- **Consistency**: Maintain the established code structure (Features-based architecture).
